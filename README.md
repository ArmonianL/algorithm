# Algorithm Knowledge Base

> **只保存压缩完的知识。**
>
> **按知识组织，而不是按题目组织。**

## 目录

- `templates/`
  - 只放可直接复用的代码
  - 一个 `.cpp` = 一个真正的模板
  - 不放完整题解、经典题代码、题目特有逻辑

- `notes/algorithms/`
  - 放属于具体算法体系的知识
  - 例如 DP、图论、字符串、数学、数据结构等

- `notes/techniques/`
  - 放跨算法的通用思维
  - 例如贡献法、维护代替重复计算、正难则反、不变量等

- `notes/cpp/`
  - 放 C++ / STL / 实现细节 / 易错点

## Notes 规则

一个 `.md` 对应一个稳定主题。

一个 `##` 对应一个知识单元：

```md
## 定位标题

- 收获 1
- 收获 2
- 收获 3

```cpp
// 可选：值得保存的代码片段
```

**来源：** [题目](链接)

```

规则：

- `##` 主要用于定位，不必完整表达知识内容
- 真正的收获写在 `-` 中
- 一个知识单元可以只有一句话，也可以是完整经典模型
- 一道题可以产生多个知识单元
- 一个知识单元也可以由多道题补充
- 题目链接可选，一般放单元末尾
- 经典题可以直接用题目名作为 `##`
- 有代码块不代表它是 template

## Template 判断

只问：

> **换一道题后，这段代码是否可能直接复制使用？**

是 → `templates/`

否 → 放在对应 `notes` 中。

## 刷题后

只保存真正新增的知识：

- 可复用代码 → `templates`
- 具体算法知识 → `notes/algorithms`
- 通用思维 → `notes/techniques`
- C++ / 实现细节 → `notes/cpp`
- 没有新知识 → 不记录
