# README

算法笔记，记录值得复习的知识、易错点和可复用的解题思维。

## 目录结构

- `algorithms/`　**具体算法**。一个算法一篇。
- `techniques/`　通用**算法思维**。一个通用思路一篇。
- `cpp/`　记录 C++ 语法、实现细节和常犯的错误。
- `00-Review.md`　复习清单。

## 怎么记

二级标题写**关键结论或自测问题**，下面放原题超链接，再用自己的话写清理由。

新收获优先补进已有笔记。同一个判断能跨题型复用时，再提炼到 `techniques/`。没有新收获的题可以只练不记。

## 怎么复习

平时把想重做的题直接放进 `00-Review.md`。每周日独立重写本周加入的题和上周留下的题。**独立 AC 就删掉链接，仍然卡住就留到下周。**

> 记录的目的不是收藏知识，而是让思路能够被再次调用。
