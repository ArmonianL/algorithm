##  用维护代替重复计算

> **核心思想：外层状态变化以后，优先复用上一轮内层循环的「进度」或「结果」，而不是从头算一遍。**

遇到二重循环，不要先急着套某个数据结构，而是先问：**内层循环到底算出了什么？下一轮会改变什么？** 如果旧信息仍然有效，就把它保存下来，随状态变化做少量更新。

最常见的三种形式：

| 可复用的东西           | 维护方式         | 典型做法             |
| ---------------- | ------------ | ---------------- |
| **扫描进度**：上次走到哪里  | 指针不回头        | 双指针、滑动窗口         |
| **计算结果**：上次求出了什么 | 从旧结果增量更新     | 前缀最值、计数、状态递推（DP） |
| **昂贵操作所需的信息**    | 在其他修改发生时同步维护 | 额外数组、维护和/计数、数据结构 |

思考顺序可以固定成：**先写出朴素枚举 → 找到重复工作 → 判断旧信息是否仍有效 → 设计更新方式 → 再分析总复杂度。**

注意：只有能证明维护的信息足够回答当前问题、且更新成本足够低时，才能这样优化。**「维护」不是不计算，而是把重复计算改成必要的增量计算。**

## $\max_{i<j}(a_i+b_j)$ 

原本枚举所有满足 $i<j$ 的数对，复杂度为 $O(n^2)$。

关键是把两维拆开：**固定右端点 $j$ 后，只需知道它前面所有 $a_i$ 的最大值**。

$$
\max_{i<j}(a_i+b_j)
=\max_j\left(\max_{i<j}a_i+b_j\right)
$$

于是边枚举 $j$，边维护 `best = max(a[0], ..., a[j-1])`：

```cpp
long long best = LLONG_MIN, ans = LLONG_MIN;
for (int j = 0; j < n; ++j) {
    if (j > 0) ans = max(ans, best + b[j]); // 只用 i < j 的信息
    best = max(best, a[j]);                  // 再加入当前位置
}
```

**关键细节：先查询，后更新**，否则会错误地把 $i=j$ 也算进去。时间复杂度降为 **$O(n)$**，额外空间 **$O(1)$**。

**收获：二维枚举能否拆成「当前这一维 + 另一维的历史统计信息」？能的话，就不必反复枚举历史。**

## [Inverse and Swap](https://atcoder.jp/contests/abc470/tasks/abc470_d) 

题目对一个排列 $P$ 反复执行两类操作：

- `1 x y`：交换位置 $x,y$ 上的元素。
- `2`：把整个排列变成它的**逆排列**。

直接处理第二类操作，每次都重新构造逆排列，要花 $O(n)$。原笔记抓住的要点是：**别等到昂贵操作发生才计算；做其他操作时，就顺手把它需要的结果维护好。**

同时维护两个互为逆的数组：

$$
P[i]=v \quad\Longleftrightarrow\quad inv[v]=i
$$

- 交换位置 $x,y$：不仅交换当前排列中的两个值，也同步更新其逆数组中这两个值对应的位置，**$O(1)$**。
- 取逆排列：两个数组早就维护好了，只需切换「当前使用的是哪一个数组」，**$O(1)$**。

下面是核心操作的伪代码（`cur`、`other` 始终互为逆排列）：

```cpp
// cur 是当前排列，other 是它的逆排列
int vx = cur[x], vy = cur[y];
swap(cur[x], cur[y]);
other[vx] = y;
other[vy] = x;

// 取逆：不需要循环重建，只需交换两个数组的角色
swap(cur, other); // 表示交换角色；实际实现可用标志位 O(1) 切换
```

实际实现用两个固定数组 `p`、`inv` 和一个布尔标志记录当前角色，避免对整个 `vector` 做数据拷贝；每次交换操作应修改当前角色对应的数组及其逆数组。这样预处理 $O(n)$，之后每次操作都是 **$O(1)$**，总复杂度 **$O(n+q)$**。

**收获：有「便宜修改 + 昂贵重算」的操作组合时，考虑让便宜修改顺便维护昂贵结果，把将来的重算变成直接切换或查询。**

## [Falling Concrete](https://codeforces.com/problemset/problem/2266/D)

**第一步不是优化循环，而是先完成建模。** 一次操作中，路段的位置变化多少，高度也同方向变化多少，因此对每个路段：

$$
\boxed{b_i=a_i-i\quad(\text{高度}-\text{位置是不变量})}
$$

要使连续 $k$ 个位置高度相同，这 $k$ 个路段的不变量就必须是 **$k$ 个互不相同的连续整数**。题目可转化为：

> **把所有 $a_i-i$ 排序、去重，求最长连续整数段的长度。**

例如排序去重后是 `1 2 3 4 8 9 10`，答案为 `4`。

**视角 A：枚举左端点，复用「扫描进度」。**

朴素做法是每换一个左端点 `l`，都从头向右找最远的 `r`。但左端点从 `1` 变成 `2` 时，已知的连续段 `1 2 3 4` 不会突然失效；**右端点不必回头**。

```cpp
int r = 0, ans = 0;
for (int l = 0; l < m; ++l) {
    r = max(r, l); // 到了新连续段时，确保 r 不落在 l 左边
    while (r + 1 < m && b[r + 1] == b[r] + 1) ++r;
    ans = max(ans, r - l + 1);
}
```

`l`、`r` 都只向右走，所以**整个扫描是 $O(m)$，而非 $O(m^2)$**。这里的 `r` 本质上就是保存了上次内层循环的**进度**。

**视角 B：枚举右端点，复用「计算结果」。**

改成询问「以当前位置结尾的最长连续段有多长」。设上一位置的长度为 `cnt`：

$$
cnt\leftarrow
\begin{cases}
cnt+1,&b[i]=b[i-1]+1\\
1,&\text{否则}
\end{cases}
$$

```cpp
int cnt = 0, ans = 0;
for (int i = 0; i < m; ++i) {
    if (i > 0 && b[i] == b[i - 1] + 1) ++cnt;
    else cnt = 1;
    ans = max(ans, cnt);
}
```

这里保留的是上一次内层循环算出的**结果**，也可以理解为只保留上一状态的 DP。**只关心长度，不关心具体左端点，因此 `cnt` 比维护整个区间更简洁。**

还可以从左端点视角进一步发现：一整段连续区间确定后，内部后续起点不可能得到更长答案，因此可以**整段跳过**。

**最终推荐：排序去重 $O(n\log n)$，再用 `for + cnt` 扫描 $O(n)$。** 这题最重要的两层收获是：**先找不变量完成转化；再复用内层循环做过的工作。**

## [ABC|ABC|ABC](https://atcoder.jp/contests/abc485/tasks/abc485_d)

我找到包含ABC的左右边界了，关键是中间段怎么处理？不要想找到中间段包含ABC的最小段。
其实本质就是一个计数问题：两个切割位置 (i,j)，需要你枚举这两个位置，这样就变成二维枚举问题了

### 思路

**1. 固定第二刀** `j`

不再枚举第一刀 `i`，而是直接统计合法的 `i` 有多少个。

**2. 维护最后出现的位置**

枚举 `j` 时，维护 A、B、C 最后一次出现的位置：

$$
p=\min(last_A,last_B,last_C)
$$

因为中间段 `[i+1,j]` 必须包含 ABC，所以：

$$
i<p
$$

**3. 利用边界确定合法区间**

第一段包含 ABC，要求：

$$
i\ge left
$$

因此合法的第一刀范围为：

$$
\boxed{left\le i<p}
$$

对当前 `j` 的贡献为：

$$
\boxed{\max(0,p-left)}
$$

枚举所有 `j < right`，累加贡献即可。
