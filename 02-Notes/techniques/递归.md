## 汉诺塔问题

- n个盘子在A柱，求移动到C柱的最少步数d[n]
- 最大的盘子肯定最后放。所以永远分3步，编号1-n-1盘子移到B，编号n盘子移动到C。编号1-n-1盘子移动到C
- d[n]=d[n-1]+1+d[n-1]=2d[n-1]+1;d[1]=1;解的：d[n]=2^n-1

```cpp
//输出路径

void hanoi(int n,char st,char helper,char ed)//将编号为1-n的n个塔从st柱移动到ed柱，helper为辅助柱

{

    if(n==1)    

    {

        cout << 1 << " " << st << "->" << ed << '\n';

        return;

    }

  

    hanoi(n-1,st,ed,helper);

    cout << n << " " << st << "->" << ed << '\n';

    hanoi(n-1,helper,st,ed);

}
```
