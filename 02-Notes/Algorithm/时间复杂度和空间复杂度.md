# ACM / 笔试题时间复杂度与算法选择指南

一般 ACM 或笔试题的时间限制为 **1 秒～2 秒**。

在这种情况下，C++ 程序的操作次数通常控制在：

> **$10^7 \sim 10^8$ 级别以内较为稳妥**

下面根据不同的数据规模，给出常见的时间复杂度要求以及适合选择的算法。

---

## 不同数据范围对应算法

| 数据范围          | 推荐复杂度                           | 常用算法                                                     |
| :---------------- | :----------------------------------- | :----------------------------------------------------------- |
| `n ≤ 30`          | 指数级别                             | DFS + 剪枝、状态压缩 DP                                      |
| `n ≤ 100`         | `O(n³)`                              | Floyd、DP、高斯消元                                          |
| `n ≤ 1000`        | `O(n²)`、`O(n² log n)`               | DP、二分、朴素版 Dijkstra、朴素版 Prim、Bellman-Ford         |
| `n ≤ 10000`       | `O(n√n)`                             | 块状链表、分块、莫队                                         |
| `n ≤ 100000`      | `O(n log n)`                         | 排序、线段树、树状数组、set/map、heap、拓扑排序、Dijkstra + heap、Prim + heap、Kruskal、SPFA、凸包、半平面交、二分、CDQ 分治、整体二分、后缀数组、树链剖分、动态树 |
| `n ≤ 1000000`     | `O(n)` 或常数较小的 `O(n log n)`     | 单调队列、Hash、双指针扫描、BFS、并查集、KMP、AC 自动机、排序、树状数组、heap、Dijkstra、SPFA |
| `n ≤ 10000000`    | `O(n)`                               | 双指针扫描、KMP、AC 自动机、线性筛素数                       |
| `n ≤ 10^9`        | `O(√n)`                              | 判断质数                                                     |
| `n ≤ 10^18`       | `O(log n)`                           | 最大公约数、快速幂、数位 DP                                  |
| `n ≤ 10^1000`     | `O((log n)^2)`                       | 高精度加减乘除                                               |
| `n ≤ 10^10000000` | `O(log k × log log k)`（`k` 为位数） | 高精度加减、FFT / NTT                                        |
