# KMP

## 核心思想

**复用已有匹配信息，避免重复比较。** [[用维护代替重复计算]]

失配时，不让主串回退，而是利用模式串自身的前后缀信息，跳到下一个可能继续匹配的位置。

**暴力：失配 → 整体右移一格 → 从头比。**  
**KMP：失配 → 根据已有信息跳转 → 接着比。**

## 关键理解

> KMP 里的“前缀”和“后缀”通常指**真前缀、真后缀**，也就是不能等于整个字符串本身。

### KMP匹配过程

$j$是已经匹配的个数。其实就是每次$i++$然后看$j+1$所对应的匹不匹配，如果匹配$j$就$++$，进入下一轮循环，如果不匹配$j$就往后退（模式串往前走），继续重复上面的匹配。

### 求ne数组

$ne[i]$构造时和匹配时差不多，上面是完整的串，$i$从2开始，因为每次回退下面的串长度只会更小，所以用前面的已经确定的$ne[i]$来不断生成后面的$ne[i]$。

- `ne[i]` 相比 `ne[i-1]`，最多只能增加 1；但可以不变，也可以一下下降很多。
