深度优先搜索

## 核心思想

## 算法流程

## 关键理解

这个问题问得更准确了。**回溯搜索（Backtracking）**本身才是竞赛里大家说“DFS”的主要场景之一。

严格来说，回溯搜索也没有一个官方固定分类，但在算法竞赛中，通常按照**搜索空间的形态**分成下面几类。

---

# 1. 排列型回溯（Permutation）

## 核心特点：

> 每一层决定一个“位置”放谁。

也就是说：

**顺序有影响。**

---

例如：

从：

```
1 2 3
```

选全部排列：

答案：

```
123
132
213
231
312
321
```

为什么有：

```
123
```

和：

```
213
```

因为位置不同。

---

搜索树：

```
             空
        /     |     \
       1      2      3
     /  \    / \    / \
    2    3  1  3  1   2
```

---

代码特点：

有：

```cpp
vis[i]
```

因为一个元素只能用一次。

模板：

```cpp
void dfs(int step)
{
    if(step==n)
    {
        输出;
        return;
    }

    for(int i=1;i<=n;i++)
    {
        if(!vis[i])
        {
            vis[i]=true;

            path[step]=i;

            dfs(step+1);

            vis[i]=false;
        }
    }
}
```

---

典型题：

- 全排列
    
- 排队问题
    
- N皇后（也属于排列思想）
    

---

# 2. 组合型回溯（Combination）

## 核心特点：

> 只关心选了哪些，不关心顺序。

---

例如：

从：

```
1 2 3 4
```

选两个。

答案：

```
12
13
14
23
24
34
```

不会出现：

```
21
31
```

因为：

```
{1,2}
```

和：

```
{2,1}
```

一样。

---

所以需要一个：

```cpp
start
```

限制搜索方向。

模板：

```cpp
void dfs(int start,int cnt)
{
    if(cnt==k)
    {
        输出;
        return;
    }

    for(int i=start;i<=n;i++)
    {
        path.push_back(i);

        dfs(i+1,cnt+1);

        path.pop_back();
    }
}
```

---

注意：

这里没有 `vis`。

为什么？

因为：

选了1之后：

下一层从2开始。

天然避免：

```
21
```

---

典型题：

- 组合数
    
- 选 k 个数
    
- 子集大小限制
    

---

# 3. 子集型回溯（Subset / 0-1选择）

这个和组合很像，但更强调：

> 每个元素只有两个状态。

---

例如：

砝码：

```
1 10 20
```

每个：

```
选
不选
```

搜索：

```
          开始
        /      \
      选1      不选1
     /           \
  选10          不选10
```

---

模板：

```cpp
void dfs(int i)
{
    if(i>n)
    {
        处理答案;
        return;
    }

    // 选
    dfs(i+1);

    // 不选
    dfs(i+1);
}
```

---

区别：

组合：

```
我要选几个？
```

子集：

```
每个东西决定要不要
```

---

典型：

- 0/1背包 DFS
    
- 子集和
    
- 状态枚举
    

你的 P5194 就属于这个。

---

# 4. 划分型回溯（Partition）

## 核心：

> 把一个整体拆成若干部分。

---

例如：

字符串：

```
aab
```

分割成回文串：

答案：

```
a|a|b
aa|b
```

---

每一步：

决定：

```
下一段切哪里
```

---

模板：

```cpp
void dfs(int start)
{
    if(start==n)
    {
        输出;
        return;
    }

    for(int i=start;i<n;i++)
    {
        if(满足条件)
        {
            选择这一段;

            dfs(i+1);

            撤销;
        }
    }
}
```

---

典型：

- 回文串分割
    
- IP地址恢复
    

---

# 5. 棋盘/填充型回溯（Placement）

## 核心：

> 往一个空间放东西。

---

例如 N 皇后：

棋盘：

```
....
....
....
....
```

每层：

```
放一行皇后
```

---

模板：

```cpp
dfs(row)
{
    if(row==n)
        return;

    for(每一列)
    {
        if(可以放)
        {
            放;

            dfs(row+1);

            撤销;
        }
    }
}
```

---

典型：

- N皇后
    
- 数独
    
- 填字游戏
    

---

# 总结表

|类型|一层代表|是否需要vis|例子|
|---|---|---|---|
|排列型|填一个位置|需要|全排列|
|组合型|选一个元素|不需要|选k个数|
|子集型|决定一个元素选不选|不需要|0/1背包|
|划分型|切一段|不一定|回文分割|
|填充型|放一个物体|看情况|N皇后|

---

对于你现在学 DFS，我建议优先掌握顺序：

```
1. 子集型（最简单）
        ↓
2. 组合型
        ↓
3. 排列型
        ↓
4. 划分型
        ↓
5. 棋盘型
```

因为前三个其实是一家：

- 子集：每个物品二选一
    
- 组合：选择几个
    
- 排列：不仅选择，还考虑顺序
    

你这道 P5194 就是很典型的**子集型回溯**。你之前写成排列型，是因为你把“选择过程的顺序”误认为了“答案的一部分”。这也是初学 DFS 最常见的坑。

---

**优化dfs考虑**  
  - 搜索顺序
  - 剪枝（利用题目数据的特殊性质，比如增长很快，考虑前缀和来剪枝）
