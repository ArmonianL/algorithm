# 二分

## 核心思想

# 一、二分（Binary Search）

## 核心：

> **二分 = 找单调性质的边界。**

利用单调性：

```text
左区 | 右区
     ↑
    边界
```

每次排除一半范围。

------

# 二、二分答案（Binary Search on Answer）

## 核心：

> **当你猜一个答案 x 时，可以快速判断 x 是否可行，并且“可行性”随着 x 增大呈单调变化。**

------

## 做题三步：

① **猜答案 x**

↓

② **check(x)**

判断：

```text
x 是否可行
```

↓

③ **利用可行性的单调性二分边界**

------

# 三、二分答案两种模型

## 1. 最大化最小值

目标：

> 让最小值尽可能大。

转化：

> 能否达到 ≥ x？

特点：

> x 越大，要求越高，越难满足。

性质：

```text
√ √ √ √ | × × ×
```

答案：

> **最后一个 √（最大可行值）**

------

## 2. 最小化最大值

目标：

> 让最大值尽可能小。

转化：

> 能否做到 ≤ x？

特点：

> x 越大，限制越宽，越容易满足。

性质：

```text
× × × | √ √ √
```

答案：

> **第一个 √（最小可行值）**

------

# 四、最终口诀

> **猜答案，写 check；**
> **看单调，找边界。**
>
> **最大找最后可行，**
> **最小找第一个可行。**

------

# 五、最核心一句话

> **二分答案的本质：把求最优解，转化为判断某个答案是否可行；只要可行性随着答案变化具有单调性，就可以二分找到边界。**

（记忆顺序：**二分找边界 → 二分答案猜 x → check 可行性 → 单调 → 二分**）

## 算法流程

- 左性质右边界：mid=(l+r+1) >> 1;
- 右性质左边界：mid=(l+r) >> 1;

## 关键理解

### 左性质右边界为什么要+1

当l=r-1时，mid=(l+r) >> 1=l;，更新l=mid=l，这样就会死循环

## 适用场景

有单调性的一定可以二分，二分不一定需要单调性

## 时间复杂度

$O(\log n)$

## 易错点

- **浮点**二分的变量一定要是`double`!!!
