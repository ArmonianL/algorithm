### 左性质右边界为什么要+1

当l=r-1时，mid=(l+r) >> 1=l;，更新l=mid=l，这样就会死循环

### 具体方案是否存在

整数二分求出的边界，具体方案不一定存在。浮点二分求出的边界，具体方案一定存在

## 二分答案

### 理解

#### 核心：

> **当你猜一个答案 x 时，可以快速判断 x 是否可行，并且“可行性”随着 x 增大呈单调变化。**

------

#### 做题三步：

① **猜答案 x**

↓

② **check(x)**

判断：

```text
x 是否可行
```

↓

③ **利用可行性的单调性二分边界**

------

#### 三、二分答案两种模型

##### 1. 最大化最小值

目标：

> 让最小值尽可能大。

转化：

> 能否达到 ≥ x？

特点：

> x 越大，要求越高，越难满足。

性质：

```text
√ √ √ √ | × × ×
```

答案：

> **最后一个 √（最大可行值）**

------

##### 2. 最小化最大值

目标：

> 让最大值尽可能小。

转化：

> 能否做到 ≤ x？

特点：

> x 越大，限制越宽，越容易满足。

性质：

```text
× × × | √ √ √
```

答案：

> **第一个 √（最小可行值）**

------

### check函数

- check函数检查的一定是**不等式**关系，不是等式关系。等式关系最后去边界上找

## 给定正整数数组，求平均值最大的，长度不小于L的连续子数组

- 方案可行：能找到平均值>=x且长度>=L的子数组，x越小，可行性越高
- 平均值>=x 转化为 每个位置减掉x后的和非负

```cpp
bool check(double x)//能否找到平均值>=x且长度>=L的子数组

{

    double b[N];

    for(int i=1;i<=n;i++) b[i]=a[i]-x;

    //找长度>=L的连续子数组的最大和

  

    double s[N];

    s[0]=0;

    for(int i=1;i<=n;i++) s[i]=s[i-1]+b[i];

    double ans=-INF;//合法的最大和

    double min_val=INF;//维护合法的前缀最小值

    for(int i=l;i<=n;i++)//枚举右端点

    {

        min_val=min(min_val,s[i-l]);

        ans=max(ans,s[i]-min_val);

    }

  

    if(ans>=0) return true;

    else return false;

}
```
