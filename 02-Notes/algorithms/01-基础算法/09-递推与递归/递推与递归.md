## 汉诺塔问题

### 经典三塔
- n个盘子在A柱，求移动到C柱的最少步数`d[n]`
- 最大的盘子肯定最后放。所以永远分3步，编号1-n-1盘子移到B，编号n盘子移动到C。编号1-n-1盘子移动到C
- $d[n]=d[n-1]+1+d[n-1]=2d[n-1]+1$,$d[1]=1$ 解得：$d[n]=2^n-1$

```cpp
//输出路径

void hanoi(int n,char st,char helper,char ed)//将编号为1-n的n个塔从st柱移动到ed柱，helper为辅助柱

{

    if(n==1)    

    {

        cout << 1 << " " << st << "->" << ed << '\n';

        return;

    }

  

    hanoi(n-1,st,ed,helper);

    cout << n << " " << st << "->" << ed << '\n';

    hanoi(n-1,helper,st,ed);

}
```

### 四塔

- n个盘子在A柱，求移动到D柱的最少步数`f[n]`
- 依然分三步：
  1.将前i个盘子移动到B柱（为什么不能分散到B柱和C柱，因为这样的话，后面移动A柱下面的大盘子的时候没有辅助柱子了，也就是不能移动到B和C柱，因为B和C柱的盘子小）
  2.将A柱剩下的盘子移动到D柱（相当于3塔问题）
  3.将B柱的i个盘子移动到D柱
- $ans=\min_{1\le i<n}\{f[i]+d[n-i]+f[i]\}=\min_{1\le i<n}\{2f[i]+d[n-i]\}$

下面`f[n]`采用递归+记忆化，`d[n]`采用递推

```cpp
int d[N],ff[N];

  

int f(int n)

{

    if(n==1) return 1;  

    if(ff[n]!=-1) return ff[n];

  

    int res=INF;

    for(int i=1;i<n;i++)

    {

        res=min(res,2*f(i)+d[n-i]);

    }

    return ff[n]=res;

}
```
