## 双指针

### 一、双指针的两种主流写法

**① 外层枚举右端点（更推荐）**

通常采用左闭右闭区间 `[j,i]`。

```cpp
for(int i=1,j=1,sum=0;i<=n;i++)
{
    sum+=a[i];

    while(sum>k)
        sum-=a[j++];

    ans+=i-j+1;
}
```

核心：**加入右端点 → 收缩左端点 → 统计答案。**

**② 外层枚举左端点（尺取法常见写法）**

通常采用左闭右开区间 `[i,j)`。

```cpp
for(int i=1,j=1,sum=0;i<=n;i++)
{
    while(j<=n && sum+a[j]<=k)
        sum+=a[j++];

    ans+=j-i;

    if(j==i) j++;
    else sum-=a[i];
}
```

核心：**扩展右端点 → 统计答案 → 移动左端点。**

两者时间复杂度都是 $O(n)$。以上模板适用于非负数组、$k\ge0$，统计区间和不超过 $k$ 的非空子数组数量。

**区别：** 外层右端点通常更容易处理空窗口；两种区间开闭方式只是习惯，并非强制规定。

### 二、双指针的本质

双指针能够优化到 $O(n)$，依靠两个关键条件：

1. **单调性：** 指针只向前移动，不需要回退。
2. **批量计数：** 找到合法区间的分界点，一次统计多个答案。

例如非负数组，固定右端点 `i`：

```text
不合法左端点 | 合法左端点
           ↑
           j
```

当 `[j,i]` 满足 `sum<=k` 时，所有 `[j+1,i]`、`[j+2,i]` 等区间也合法。

因此：

$$
\boxed{ans+=i-j+1}
$$

而不是简单地 `ans++`。

### 三、为什么这道题不能直接 `sum==k` 就 `ans++`？

因为数组中存在 `0`。

例如：

```text
a = [0, 1, 0]
k = 1
```

合法区间共有 4 个：

```text
[0,1]
[1]
[0,1,0]
[1,0]
```

固定一个右端点，可能有多个左端点满足 `sum==k`。

所以：

```cpp
if(sum==k) ans++;
```

会漏解。

**解决方法：转化为更容易批量统计的问题。**

$$
\boxed{
count(sum=k)=count(sum\le k)-count(sum\le k-1)
}
$$

对于 `sum<=k`，合法左端点形成连续区间，可以利用双指针找到分界点，一次统计所有答案。

这不意味着 `sum==k` 不能使用双指针，而是直接判断一次不够；也可以通过额外计数处理。

### 四、本题最标准的思路

**二维降维 + 双指针**

1. 枚举矩形上下边界：$O(H^2)$。
2. 将这几行压缩为一维列和数组 `col`：$O(W)$。
3. 双指针统计 `calc(k)-calc(k-1)`：$O(W)$。

最终时间复杂度：

$$
\boxed{O(H^2W)}
$$

记得答案使用 `long long`。

---

### 最值得记住的三句话

**① 双指针的核心是单调性：** 两个指针只向前移动，不回退。

**② 双指针计数的核心是批量统计：** 找到合法区间的分界点，而不是逐个枚举。

**③ 当直接统计难以处理时，尝试转化问题：**

$$
\boxed{\text{恰好}= \text{至多}-\text{严格小于}}
$$

**这道题最大的收获不是学会一个双指针模板，而是学会利用单调性，将逐个枚举答案变成一次性统计答案。**
