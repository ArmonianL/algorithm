
| 概念 | 属于哪一层 | 本质 | 常见实现 | 主流实现 | 和其他概念的关系 |
|---|---|---|---|---|---|
| **递归** | **实现方式** | 函数调用自己，把问题交给更小的子问题 | 函数自调用 | **函数递归** | 常用来实现 DFS、回溯、记忆化搜索 |
| **递推** | **实现方式** | 从已经算出的状态推出新状态 | `for` / `while` | **for 循环** | 常用来实现 DP |
| **DFS** | **搜索策略** | 一条路先走到底，再返回 | 递归 / 显式栈 | **递归** | 属于搜索；经常用递归实现 |
| **BFS** | **搜索策略** | 按层扩展状态 | 队列 | **队列 + while** | 属于搜索；常用于无权图最短路 |
| **搜索** | **算法思想** | 在所有可能状态中探索答案 | DFS / BFS / 回溯 | **看题目选择** | DFS、BFS 都是搜索的方法 |
| **DP** | **算法思想** | 利用子问题答案，避免重复计算 | 递推 / 记忆化搜索 | **递推** | 核心是状态 + 状态转移 |
| **记忆化搜索** | **DP 的实现形式** | 递归求状态，并保存已经算过的答案 | 递归 + `dp` 数组 | **递归 + 记忆化** | 可以理解成“递归版 DP” |

最核心的分层：

| 层次 | 概念 |
|---|---|
| **算法思想** | 搜索、DP |
| **搜索策略** | DFS、BFS |
| **实现方式** | 递归、递推 |
| **组合形式** | 记忆化搜索 = DP + 递归 + 缓存 |

最常见搭配：

| 算法 | 最主流写法 |
|---|---|
| **DFS** | 递归 |
| **BFS** | 队列 |
| **普通 DP** | `for` 循环递推 |
| **记忆化搜索** | 递归 + `dp` 缓存 |
| **树形 DP** | DFS递归 + DP |

所以最值得记的是：

$$
\boxed{\text{递归、递推 = 怎么实现}}
$$

$$
\boxed{\text{DFS、BFS = 怎么搜索}}
$$

$$
\boxed{\text{搜索、DP = 用什么思想解决问题}}
$$

于是它们完全不冲突，例如：

$$
\boxed{\text{DP + 递推}}
$$

是最常见的普通 DP；

而

$$
\boxed{\text{DP + 递归 + 记忆化}}
$$

就是记忆化搜索。
