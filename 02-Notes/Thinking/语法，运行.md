数组越界什么都可能发生，可能会TLE  
  - `int` 数组：
    - `memset(a, 0, sizeof(a))` ✅ 全部变成 `0`
    - `memset(a, -1, sizeof(a))` ✅ 常见环境下全部变成 `-1`
    - `memset(a, 1, sizeof(a))` ❌ 不会变成 `1`，通常会变成 `16843009`
 - `bool` 数组：
    - `memset(vis, false, sizeof(vis))` ✅
    - `memset(vis, true, sizeof(vis))` ✅ 常见环境下可以

一定要考虑数据范围，`long long`！！！！

```
while(b[j]!=a[i] && j<=m)
```

C++ 的 `&&` 是从左往右判断的，所以会**先访问** **`b[j]`**，再判断 `j<=m`。

如果此时 `j=m+1`，就已经访问越界了。

应该写成：

```
while(j<=m && b[j]!=a[i])
```

先保证 `j` 没越界，再访问 `b[j]`。
