## 我的思路

## 正确思路

1. 用筛法，不要每个判断都用试除法
2. 剪枝不仅要考虑素数，还要考虑合法日期。如果前面就不是素数或者前面几位就不是合法的就剪掉

## 实现注意

```c++
if(month==2)
{
    if(run)
    if(!(day>=1 && day<=29)) return false;
    else if(!(day>=1 && day<=28)) return false;
}
```

等价于

```cpp
if(month==2)
{
    if(run)
    {
        if(!(day>=1 && day<=29))
            return false;
        else if(!(day>=1 && day<=28))
            return false;
    }
}
```
