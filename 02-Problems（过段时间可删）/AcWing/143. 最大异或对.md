## 正确思路

每个整数当成二进制，从最高位开始存。因为如果最高位是1肯定会让这个结果更大

### 查询

查询一个 `x`，都最多走 **31 层**。

所以一次查询：

O(31)=O(1)

遍历 `N` 个数，每个查询一次：

O(31N)=O(N)

插入也是一样，每个数走 31 层：

O(31N)

因此“边查边存”：

```
query(x);
insert(x);
```

总共大约：

31N+31N=62N

而“全部存完，再全部查询”：

```
for (...) insert(x);
for (...) query(x);
```

也是：

31N+31N=62N

### 所以两种写法时间复杂度几乎一样
